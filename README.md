# Description
The upcoming Scratch 2.0 revival, which would likely release sooner.
# What is this?
This will be an upcoming Scratch 2.0 revival, which would simply feature tons of interesting feature, similar to Dimod, and PengiunMod.
# What will it feature?
Well, as about the concept, we were thinking of it having stuff like:
- Pink mode would be the primary, while the Original Mode would be the secondary, there will be Light, Dark and Darker themes too.
- Probably some stuff from Scratch 3.0, but modified to make them look like the Scratch 2.0 stuff or such.
- It would have BOTH sounds from Scratch 1.X, and Scratch 3.0.
- Features on where you are able to pitch the audio without speeding.
- VST Plugins support for audio, and the audio editor.
- Profanity support (unconfirmed).
- And so on....
